# KillTracker

KillTracker is a Minecraft plugin designed to track player kills and display a Discord server link. It provides commands to set and display team names, show kill counts, and access the Discord server. The plugin is built using the Spigot API and Adventure library for text components.

## Install

1. Download the KillTracker plugin JAR file from the releases section.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your server to enable the plugin.

## Use

1. **Set Team**: Use the command `/team <teamName>` to set your team. This will display your team name in the tab list.
2. **Show Kills**: Use the command `/kills` to display your current kill count.
3. **Discord Link**: Use the command `/discord` to get the link to the Discord server.
